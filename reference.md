# reference.md — синтез по референс-доске (Фаза 2)

7 живых эталонов разобраны (скрины в `refs/`, разбор в `refs/_manifest.json`, honest shortfall 7/10 — ниша узкая, большинство похожих услуг живут в агентствах-маркетплейсах, не как брендовые сайты одного артиста).

## 1. Идеальная структура (откуда взято)

1. **Hero** — кинематографичный full-bleed кадр (у Don Diablo — огонь и толпа; у нас — LED-барабаны/неон с живых сетов) + короткий H1-удар + двойной CTA (у Romb Drums: "Bring this energy" + "Watch it live") → берём эту связку
2. **Proof-бар сразу под героем** — реальные площадки + цифра (у Romb Drums: "Performed at JW Marriott, Bastian..." · подписчики · тэглайн) → у нас: JW Marriott / W Hotel / OCCO / Zion + "с 2014"
3. **Bio/About** — короткие абзацы-факты, не вода (у Mili Sax: "WHO IS MILI" — лейблы, коллаборации, фактура; у Cuebur — карточки "roots/bridge/energy") → у нас факты из пресс-кита
4. **"Без меня / Со мной"** — уже есть готовый блок с ROMB-Drums-Site (наш эталон, голова Пула A), просто переносим механику и материал
5. **Venues/proof-стена** — список реальных площадок как отдельный визуальный блок (у Cuebur — таблица в разделе Press; у Romb Drums — маркиз-бегущая строка) → у нас: JW Marriott/W Hotel/OCCO/Raeeth/... полный список из пресс-кита
6. **Booking CTA + форма/канал** — у DJ Sax Live есть встроенная форма на странице (имя/дата/место), но у нас целевое действие — WhatsApp Марины (проще, меньше трения) → берём паттерн "прямой CTA-блок с контактом", не форму
7. **Подвал: райдеры + соцсети** — у Romb Drums уже есть кнопки скачать Technical/Hospitality Rider PDF + Instagram-хендлы → повторяем 1:1, у нас PDF уже готовы

## 2. Дизайн-направление (кандидаты, вход в Фазу 4)

- **Кандидат 1 — "Cuebur-редакционный":** тёмный герой со статус-строкой, кремовые вставки-паузы между тёмными блоками, карточки-таймлайн. Плюс: премиальная воздушная подача. Минус: спокойнее нашей заявленной энергии "ОГОНЬ"
- **Кандидат 2 — "Romb Drums + неон Don Diablo":** тёмный фон + золото (наш Design.md) + кинематографичный видео-герой (не статичное фото, а короткий looping-клип с одного из 9 видео Виктора) + минималистичная моноширинная деталь (countdown/статус-строка à la Don Diablo, но не таймер обратного отсчёта — у нас не запуск, а статус "Available for bookings")
- **Рекомендация:** Кандидат 2 — он прямее совпадает с уже запертой ДНК (Design.md) и с "дорого-богато + ОГОНЬ" от Марии, Кандидат 1 даёт вкус для типографики/пауз между секциями

## 3. Банк смыслов/формулировок (с атрибуцией)

- "Live percussion support for DJs" / "enhancing DJ sets with live rhythm" — точная формула из собственного пресс-кита Виктора, не с референсов
- "Strong enhancement of DJ sets with live percussion · High-energy dancefloor atmosphere · Visual and musical highlight of the event · Memorable live performance element" — готовый "what the venue gets"-блок из пресс-кита
- "Mobile party DJ and live percussion package for hire in clubs, at weddings and events" — формула позиционирования у Drums+Decks, можно адаптировать для подзаголовка
- "Bring this energy to your event" (Romb Drums CTA) — переносим логику CTA, не текст дословно (другой бренд)

## Незанятая территория (белая зона)
Ни один референс не показывает живого исполнителя как "мистическую" фигуру (шляпа/очки/золото как визуальный код) — у всех либо "весёлый DJ" (DJ Sax Live), либо "духовный проводник" (Tribal DreamZ), либо "редакционный продюсер" (Cuebur). У Manusan есть готовый визуальный код из собственных фото (чёрное/золото, шляпа, очки, поднятая рука с барабаном) — это и есть дифференциация, не у кого не подсмотрено.
