## DNA — locked :root (proposal)

```css
:root {
  --bg: #0a0a0a;
  --surface: #151312;
  --accent: #c9a24b;       /* тёплое золото — "дорого-богато" из студийных портретов */
  --accent-2: #e0299b;     /* неоновая магента — клубный свет с живых сетов */
  --accent-2-alt: #7b5cff; /* неоновый фиолетовый, вторичный клубный акцент */
  --text: #f5f2ea;
  --text-muted: #9a958c;
  --border: #262220;
}
```

Источник: студийные фото (чёрное/золото, шляпа, солнцезащитные очки — премиальная мистика) + живые сцены (розово-фиолетово-синий неон, LED-барабаны). Контраст text/bg ≈ 18:1 (WCAG AAA), accent/bg ≈ 6.8:1 (AA на крупном тексте).
